# Contributing to Quiet Home

Contributions for the noncommercial Quiet Home project are welcome through GitHub pull requests.

By submitting a contribution, you confirm that:

1. You created the contribution or have the right to submit it.
2. You license the contribution under the repository's PolyForm Noncommercial License 1.0.0 terms.
3. Your contribution contains no private device data, location-identifying media, personal screenshots, signing keys, credentials, streaming-service assets, or unlicensed third-party material.
4. You understand that accepting a contribution does not grant commercial-use permission.

Keep changes focused, explain user-visible behavior, and ensure `Build.ps1` completes before opening a pull request.
